# Tvarka ATK API

A single REST API for Lithuanian eID authentication and qualified electronic signing (QES), plus validation, timestamping and long-term-validation (LTV)/archive services. Primary ceremonies are physical smart-card reader and NFC on the Lithuanian identity card (ATK). Contract 1.4.0 (2026-08) withdrew the Smart-ID and Mobile-ID passthrough, so the ATK API is card-only; hosted remote-method ceremonies moved to the sibling Tvarka Sign API. eIDAS-aligned.

## APIs

- **Tvarka ATK API** — REST API for Lithuanian eID authentication and qualified electronic signing (QES), with validation, timestamping and LTV/archive trust services. OpenAPI 3.1 contract with Auth, Sign, Pairing, Validation, LTV and Well-known tags. Webhooks documented in OpenAPI webhooks block (signStatus event). (`https://atk.tvarka.pro/v1`)

> Two public REST APIs with valid OpenAPI 3.1 contracts, both fetched verbatim. The ATK API (v1.4.0, 22 operations) is credential-gated - HTTP Basic server-to-server behind an IP allow-list, plus a per-request ES256 JWT for the card-driving client - and production and sandbox share the host atk.tvarka.pro/v1. The Tvarka Sign API (v1.2.1, 21 operations, live since 2026-08-27) is a bearer-key orchestration surface with RFC 9457 problem details and a real remote MCP server. Published pricing is EUR 0.07 per successful ATK or trust-service operation, excluding VAT. Proprietary license.

## Second API

- **Tvarka Sign API** — post a document and a list of signers; Tvarka runs its hosted qualified signing ceremony for each of them (Smart-ID, Mobile-ID, LT ATK over NFC in the Tvarka Sign app). Nothing in the API produces a signature - a signature is a human act. (`https://sign-api.tvarka.pro`)
